How this works?

Generally there are three levels on which data can be edited:
  • 1. Experiment data
  • 2. Protocol data
  • 3. Definitions
Experiment data is an "instantiation" of the protocol data, meaning: it relies on the available medication, viruses and procedures defined for the protocol and applies all settings defined in the protocol as a default. (Of course everything can be manually edited and changed if necessary. However you may not use any medication, viruses or procedures which are not defined in the respective protocol.)

Protocol data relies on all available medication, viruses and procedures defined in the definitions and also uses the defaults entered there. The reason for doing so is mainly to avoid typos and a lot of typing in general, since multiple protocols will probably use the same procedures, medication or viruses.

Definitions define all medication, procedures and viruses that can be used in protocols. So the only place to add medication, viruses or procedures is in the definitions.

What do I do if I want to edit animal data?

Ask your self the following questions:
1. Does the protocol and sub-protocol for my animal already exist? If yes, select the corresponding sub-protocol on the overview page and start you work :)
2. If no, you must add the protocol and/ or sub-protocol first. Here you ask yourself: do all medication, viruses and procedures needed for my protocol already exist in the definitions section? Again: if they do, start creating your protocol/ sub-protocol, otherwise first create the missing medication, viruses and procedures, then continue with creating your protocol.
